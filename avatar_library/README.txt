Add reusable avatar images to a folder named avatar_library/ in your repo.
Supported files: .jpg .jpeg .png .webp

Optional manifest formats:
- avatar_library/manifest.json
- avatar_library/avatars.json

Example:
{
  "avatars": [
    {"id": "naomi", "label": "Naomi Vale", "file": "naomi.png"},
    {"id": "mason", "label": "Mason", "file": "mason.jpg"}
  ]
}
